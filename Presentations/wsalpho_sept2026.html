Small Area, Big Heart

Small Area Demographic Estimates (SADE) are a set of modeled population estimates produced by WA OFM

  • Census Block

  • 62 Race/Ethnicity Combinations

  • Sex

  • 2000 - 2025

They are the main source of denominators for WA.

Processing … please quack

With the data downloaded, and some file paths set in the script or in .Renviron, the process_data.R script will load, reformat, and save the input CSVs in to a DuckDB database.


DuckDB is a great analytical tool:

  • Local in-memory/on-disk database

  • Very fast and good at analytical workflows

  • Good flavor of SQL and interoperability with R (see also duckplyr or dbplyr)

Fetch results

The fetch_pop function extracts processed population data from the DB.

A brief aside on AOIC

Just because AOIC estimates exist and are available does not mean they mean what you think they mean (or what you want them to mean).

  • Mis-classification

    • Joshi et al (2018): Vital statistics data alone underestimated overdose mortality among AIAN people by ~40%

  • Difference in ascertainment method between data versions and data systems (e.g. Census 2010 -> Census 2020, SADE vs. Vital Registration)

  • Data processing protocols (e.g. imputation from ethnicity)

Example #4

Return the SQL code of a query that does not use AIC/AIC-NH for race (that will instead return multiple queries)

fetch_pop(
  dbpath = dbpath, geog_level = 'county', geog = 53035, year = c(2021, 2025),
  age_col = 'age_11g', age = '25-34', gender = 'Male', raceeth_col = 'race6', 
  raceeth = 'White Only', groups = c('Year', "Race/Eth"), return_query = T)[[1]]
<SQL> select
geo_id,year,race6,sum(pop) as pop
from county
WHERE geo_id in (53035) AND "year" in (2021, 2025) AND age_11g in ('25-34') AND gender in ('Male') AND race6 in ('White Only') 
GROUP BY geo_id, "year", race6
order BY geo_id, "year", race6
